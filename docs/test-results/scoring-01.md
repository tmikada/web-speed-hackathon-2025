## 分析

### スコア内訳

- **ページの表示**: 66.00 / 900.00（7.3%） — 200点未満のため他カテゴリは計測対象外
- **ページの操作**: 計測不可（ページ表示200点未満のためスキップ）
- **動画の再生**: 計測不可（ページ表示200点未満のためスキップ）

### ページ別パフォーマンス傾向

- **比較的高スコア**: ホーム(25), 番組表(25) — 基本的なLighthouseメトリクスが一部通過
- **低スコア**: 放送前/後(3.75), プレミアム(3.75), 404(4.00) — ほぼ全メトリクスが不合格
- **ゼロスコア**: 無料エピソード(0), 放送中(0) — ページが正常に表示できていない可能性

### ボトルネック

1. **巨大なバンドルサイズ**: 全コードが単一ファイル → ページ操作・動画再生が計測不可能なほど重い
2. **キャッシュ無効**: 全レスポンスに`no-store` → 毎回フルダウンロード
3. **SSR未活用**: 空のHTMLを返却 → FCP/LCPが極めて遅い
4. **Webpack非最適化**: `mode: 'none'` + `inline-source-map` → minification/tree-shakingなし

### 200点ライン到達への必要条件

ページ操作・動画再生の採点が開始されるには、ページの表示で**200点以上**が必要。
現在66点 → **+134点**必要。9ページの平均を約22点に引き上げる必要がある。

**最優先アクション**:
1. `LimitChunkCountPlugin` 削除（コード分割有効化）
2. Webpack `mode: 'production'` + `devtool: false`
3. キャッシュヘッダー設定
4. SSRの結果をHTMLに反映
